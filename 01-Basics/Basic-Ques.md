## 🧠 Recommended Practice Flow

1. Learn the concept from the lecture/notes first.
2. Try the problem yourself before opening any hint.
3. Write the solution by hand (VS Code), no copy-paste.
4. Dry-run at least one example and one edge case (`0`, negative, single digit).
5. Note the time and space complexity.
6. Only then check the editorial/video if needed.
