## 🧠 Recommended Practice Flow

1. Read the problem only.
2. Try the brute-force (linear scan) approach first.
3. Identify the pattern: plain search, boundary search (lower/upper bound), rotated array, or **search on answer**.
4. Define the search space (`low`, `high`) and the monotonic condition.
5. Write the optimal solution yourself in VS Code.
6. Dry-run at least one example.
7. Only then check the editorial/video if needed.
