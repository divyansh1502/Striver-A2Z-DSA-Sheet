## 🧩 Problem-Solving Approach

For every problem, I try to follow a consistent process:

```text
Understand
    ↓
Brute Force
    ↓
Find the Pattern
    ↓
Optimize
    ↓
Analyze Complexity
    ↓
Implement in Java
    ↓
Dry Run
    ↓
Test Edge Cases
    ↓
Revisit
```

The focus is on understanding **why an approach works**, not just memorizing code.
