## Quick lookup

| Clue in problem | Technique | Why it works | Problems I solved |
|:--|:--|:--|:--|
| "sorted array" | Binary search / two pointers | Order lets you discard half or move from both ends | |
| "subarray / substring" | Sliding window / prefix sum | Reuse work from the previous window | |
| "count / frequency / duplicate" | Hash map / set | O(1) lookup instead of re-scanning | |
| "pair with sum" | Hash map or two pointers | Find the complement quickly | |
| "all combinations / subsets" | Recursion + backtracking | Try every choice, undo it | |
| "min / max / count ways" | DP or greedy | Reuse smaller answers | |
| "next greater / smaller" | Monotonic stack | Keep candidates in order | |
| "matching / undo" | Stack | Last in, first out | |
