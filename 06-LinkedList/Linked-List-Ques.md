## 🧠 Recommended Practice Flow

1. Read the problem only.
2. Try the brute-force approach first (extra array / hashing).
3. Identify the pattern: **dummy node**, **slow & fast pointers**, **in-place reversal**, **merge**, or **hashing with node references**.
4. Draw the pointers on paper — most bugs come from the order of pointer updates.
5. Write the optimal solution yourself in VS Code.
6. Dry-run on edge cases: empty list, single node, two nodes, cycle at head.
7. Only then check the editorial/video if needed.

### 🧰 Patterns Cheat-Sheet

| Pattern | Problems |
|---|---|
| Slow & Fast pointers | Middle, Detect Loop, Loop Start, Loop Length, Palindrome, Delete Middle |
| In-place Reversal | Reverse LL, Palindrome, Reverse K-Group, Reverse LL II |
| Dummy Node | Remove Nth, Add Two Numbers, Merge Lists, Partition List |
| Two Pointers (different lengths) | Intersection of Y-LL, Rotate List |
| Merge Sort / Merge Procedure | Sort List, Flatten LL, Merge K Lists |
| Hashing / Interleaving | Clone with Random Pointer, LRU Cache |
