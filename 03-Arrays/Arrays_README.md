## 🧠 Recommended Practice Flow

1.  Read the problem only.
2.  Try the brute-force approach first.
3.  Identify the pattern.
4.  Write the optimal solution yourself in VS Code.
5.  Dry-run at least one example.
6.  Only then check the editorial/video if needed.
